# Fonts Editor

_last updated 2026-09-21_

## Creating a new font

To import a font into the engine, you must have a .png spritesheet of the font and an .idx file with the same name in the same location as the .png. Please see the [Working with Fonts and Languages](Fonts-Guide) page for more information on how to format your .png and .idx files.

## Fallback .ttf

You can set a .ttf font file to use as a backup font in case the original .png and .idx files cannot be rendered.

## Outline Font

Check this box if you want this font to render with an outline. The first color in the palette should be the primary font color and the second color will be the outline color.
